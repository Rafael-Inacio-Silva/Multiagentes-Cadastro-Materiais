# Arquitetura do Sistema

O sistema utiliza uma arquitetura baseada em múltiplos agentes.

Cada agente é responsável por extrair um tipo específico de informação a partir de um desenho técnico ou documento.

Exemplos:
- nome do item
- número do desenho
- material
- peso
- tipo do item
- estrutura

O fluxo principal será coordenado pelo arquivo `main.py`.
